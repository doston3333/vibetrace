# Support

VibeTrace is currently a pre-release project maintained on a best-effort basis.

- Use [GitHub Discussions](https://github.com/doston3333/vibetrace/discussions)
  for usage questions and design discussion when Discussions are enabled.
- Use the structured [issue forms](https://github.com/doston3333/vibetrace/issues/new/choose)
  for reproducible bugs and focused feature requests.
- Use [private vulnerability reporting](https://github.com/doston3333/vibetrace/security/advisories/new)
  for security issues. Never put secrets or private trace content in an issue.

Please include the VibeTrace commit or version, operating system, Node version,
capture adapter, safe reproduction steps, and the smallest redacted diagnostic
output that demonstrates the problem.
