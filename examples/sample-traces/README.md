# Sample traces

These five small JSONL traces are public, deterministic fixtures for adapter,
schema, dashboard, and documentation smoke tests. They contain no real user
content or credentials. Each line is a canonical `TraceEvent` v0.1 record; a
full 100-, 1,000-, and 20,000-event corpus is generated by
`@vibetrace/test-fixtures` with the scenario and seed named below.

| File                    | Scenario           | Seed |
| ----------------------- | ------------------ | ---: |
| `successful-edit.jsonl` | successful-edit    |   11 |
| `failure-retry.jsonl`   | retry-loop         |   12 |
| `correction.jsonl`      | user-correction    |   13 |
| `compaction.jsonl`      | context-compaction |   14 |
| `subagents.jsonl`       | subagent-activity  |   15 |

The examples intentionally include source provenance and raw-field preservation
so consumers can validate the same trust boundary used by the daemon.
